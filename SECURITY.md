# Segurança

## Como relatar uma vulnerabilidade

**Não abra uma issue pública.** Use o relato privado do GitHub:
<https://github.com/WamanaDev/pastel/security/advisories/new>

Inclua o que encontrou, como reproduzir e o impacto. Respondemos assim que possível
e damos o crédito a você na correção, se quiser.

## Versões com suporte

Apenas a versão mais recente (beta) recebe correções.
